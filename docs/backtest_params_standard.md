# QMT 回测参数标准设置（极尽真实版）

> 目的：别让回测成绩比实盘好看。**下面标 ❌ 的三项不改，回测就是注水成绩。**

## 一、基本信息（策略属性页）

| 项 | 常见默认 | **标准设置** | 为什么 |
|---|---|---|---|
| **启动本地Python** | 未勾 | **✅ 必须勾上** | 不勾 Python 策略根本不跑（这是最容易犯的错） |
| 名称 / 快捷键 | 随便填（如 666） | 建议改成看得懂的（如 `v3_MACDFULL`） | 多策略时不会选错 |
| 默认周期 | 日线 | **日线** ✅ | 我们的策略是日线信号 |
| 默认品种 | 512480 半导体ETF国联安 | **512480** ✅ | 与代码里 `g.stock` 一致 |
| **复权方式** | 前复权 | **前复权** ✅（如能选"等比前复权"就选它） | 份额折算会造成假摔（-50%），不复权会把策略甩下车；前复权口径与咱们研究一致 |
| 位置 | 副图 | 主图（可选，只是看图好看） | 我们的策略不画图，纯看买卖点 |
| 快速计算 / 刷新间隔 | 0 / 0.00秒 | 保持默认 ✅ | 回测无关 |
| 加密公式 | 不勾 | 不勾 ✅ | — |

## 二、参数设置页

⚠️ **把里面的参数全部清空**（截图里的 `period=14`、`sell_value=150`、`buy_value=-200` 是上一个策略遗留下来的）。
我们的 v3 策略**不读任何外部参数**（代码里没有 `get_parameter` 调用），留着不报错，但会误导后面看的人。

## 三、回测参数页

| 项 | 截图现状 | **标准设置** | 为什么 |
|---|---|---|---|
| 开始时间 | 2000-01-01 | **保持** ✅ | 从上市当天跑，不挑日子 |
| 结束时间 | 2026-10-14 | 保持 ✅ | — |
| 基准 | 000300 沪深300 | 保持 ✅ | 有个参照物 |
| 初始资金 | 100000 | **100000** ✅ | 与代码里 `g.cash=100000.0` 一致，否则仓位算错 |
| 保证金比例 | 5.0000% | 忽略（期货项） | ETF 回测无关 |
| 滑点类型 | 按成交额比例 | 保持 ✅ | — |
| **滑点值** | **0.0000%** | **❌ 改 0.1%** | 0 滑点 = 假装每次都能按信号价成交。**这是最影响真实性的一项** |
| 手续费类型 | 按成交额比例 | 保持 ✅ | — |
| 买入印花税 | 0.0000% | 保持 ✅ | **ETF 免印花税**（个股是 0.05% 单边） |
| 卖出印花税 | 0.0000% | 保持 ✅ | 同上 |
| 最低佣金 | 5.0000 元 | **保持 5** ✅ | 券商规则：单笔不足 5 元按 5 元 |
| 买入佣金 | 0.0250% | **保持 0.0250%** ✅ | = 万 2.5 |
| **平昨佣金** | **0.0000%** | **❌ 改 0.0250%** | 官方定义：**"设置股票、期货平昨佣金比例"**——**股票/ETF 卖出走这条**！填 0 = 卖出免费 = 收益虚高 |
| **平今佣金** | **0.0000%** | **❌ 改 0.0250%** | 保险项：ETF 支持 T+0，当天买当天卖算平今 |
| **最大成交比例** | **0.05%** | **改成 100%** | ⚠️⚠️ **这是"买卖只成交一点点"的元凶**。默认 0.05% = 每笔单最多只能成交当日成交量的 0.05%（实测 513100 只能成交 13,500 股，我要买 36,200 股）。账本按全量记账 → 与真实账户错位 → 后续卖出全被"持仓不足"跳过 → 净值全乱。**必须改成 100%** |

## 五、实盘上还差的最后一块（回测模拟不了的）

1. **信号时点**：回测是收盘价成交；实盘要设成 **14:55 左右运行**，用当时价近似收盘价，否则只能次日开盘买
2. **ETF 折溢价**：收盘时溢价买入 = 白亏一部分
3. **停牌/流动性**：极端行情下 ETF 可能大幅偏离净值
4. **心理成本**：满仓单只 ETF 回撤 27% 时能不能拿住，这个回测算不出来

## 六、在 QMT 里建策略的步骤（一个版本一个策略）

1. 模型研究 → 策略列表 → 点 **「+新建策略」→「Python策略」**
2. 命名**跟我们档案表的版本号对齐**（好对照）：`v3_满仓MACD`、`v4_账户实查`、`v5b_轮动`…
3. 把对应 `.py` 的全部代码粘进去 → **右键编译** → 跑回测
4. ⚠️ **不要在同一条策略里反复覆盖不同版本**——QMT 的回测参数是跟策略走的，混在一起就对不上账了
5. 跑之前先看 `策略档案.md` 里的预期成绩，跑完对照

### 首次运行注意

- 看到界面卡住**别急着点停止**——等它打印 `READY xxx`
- init 里带下载循环的版本（v5）首次会卡很久；用 **v5b**（无下载版）+ 提前在「数据管理」下好数据
- 出现 `KeyboardInterrupt: 策略被手动停止` 不是代码 bug，是被人为停掉的
