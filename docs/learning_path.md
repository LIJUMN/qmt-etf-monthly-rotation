# QMT 学习路线 —— 从零到能跑模拟策略

> 环境：迅投投研仿真终端（C:\迅投极速交易终端 睿智融科版）
> 内置 Python 3.6 · 7×24 模拟仿真交易 · 策略加密不可外传

---

## 第一步：认门牌（第 1~2 天，只看不写）

目标：把界面当自己家，闭着眼能找到功能。

打开软件后挨个点一遍这几个区，每个花 10 分钟：

1. **行情报价区**：找一只熟悉的股票（如 600519 贵州茅台），加自选，看分时/K线，试着切换周期（日K/60分钟/5分钟）
2. **交易下单区**：找到"模拟下单"入口，随便下一笔 100 股，看委托、成交、持仓三个页面怎么联动
3. **策略区**：找到"策略"或"量化"菜单，看看内置策略列表长什么样（先不跑）
4. **回测区**：找到"回测"入口，看需要填哪些参数（标的、区间、资金）

**过关标准**：能手动买 100 股、再卖掉，全程不看教程。

---

## 第二步：跑别人的策略（第 3~5 天）

目标：让现成策略在自己账户里转起来，理解"策略在跑"是什么状态。

1. 从内置策略/模板里挑一个**最简单的**（双均线、网格这类），直接加载运行
2. 盯着它跑一晚上，观察：什么时候触发委托、成交记录在哪、持仓怎么变
3. 试改参数（比如均线 5/20 改成 10/30），看行为变化
4. 有问题查论坛"常见问题查询"帖：xuntou.net 论坛 tid=901

**过关标准**：能解释这个策略"什么时候买、什么时候卖"，改参数后行为符合预期。

---

## 第三步：0 代码可视化策略（第 6~10 天）

目标：不懂 Python 也能拼出自己的策略逻辑。

- 用 QMT 自带的**可视化编辑器**（0 代码策略交易）：像拼积木一样组合"条件→动作"
- 教程：xuntou.net 论坛置顶帖《可视化编辑器（0代码策略交易）使用教程》tid=1209
- 练手目标：拼一个"5日均线上穿20日均线买入、下穿卖出"的傻瓜策略

**过关标准**：可视化拼出一个完整策略并在模拟盘跑通至少一次买卖。

## 第四步：Python 策略入门（第 2 周起，核心阶段）

目标：能读懂并独立写简单 Python 策略。

### QMT 策略的固定骨架（先背下来）

```python
def init(ContextInfo):        # 开盘前跑一次：初始化
    ContextInfo.accID = '你的模拟资金账号'
    ContextInfo.set_universe(['600519.SZ'])  # 操作哪些股票

def handlebar(ContextInfo):   # 每根K线跑一次：策略主体
    # 取数据 -> 算指标 -> 判断 -> 下单
    pass
```

就两个函数：`init` 管初始化，`handlebar` 每根K线来一次。所有策略都是往这两个筐里填肉。

| 资源 | 用途 |

### 必须记住的规矩（2026年10月新规后）

策略代码**只能在 QMT 内置编辑器里写、沙箱里跑**：

- ❌ 不能读写本地文件（open/read/write）
- ❌ 不能联网（HTTP/socket）
- ❌ 不能连数据库（MySQL/SQLite/Redis）
- ✅ 只用内置行情数据 + 内置指标库 + 下单API，一切照常

内置 Python 是 3.6，新第三方库基本装不上，能用内置的就用内置的。

**过关标准**：独立写出双均线策略的 Python 版，和第三步的可视化版本对照，买卖点一致。

## 第五步：回测算账（第 3 周起）

目标：学会用回测回答"这策略过去能赚多少钱"。

1. 把自己的策略丢进回测引擎：选标的、选时间段（建议先测 1~2 年）、初始资金设 20 万
2. 看懂四个核心数字：
   - **年化收益率**：折算到一年赚几个点
   - **最大回撤**：从最高点最多亏下来多少（这个比收益更重要）
   - **夏普比率**：每承受一份波动换回几份收益，>1 算不错
   - **胜率/盈亏比**：赢的次数占比，赢时赚多少输时亏多少
3. 调参数、再回测、对比结果——这就是量化的日常

**过关标准**：能对两个策略的回测报告说出"哪个更好、为什么"。

## 第六步：模拟盘实战（持续进行）

- 回测满意的策略挂上 7×24 模拟盘，让它自己跑
- 每天收盘花 5 分钟看持仓、成交、收益曲线
- 记策略笔记：为什么买、为什么卖、哪里和预期不符
- 模拟盘至少跑满 1 个月再谈"这策略行不行"

---

## 避坑清单

1. **别碰"独立交易"登录选项**——新规已取消，走正常登录
2. **别找第三方"破解版/绿色版"**——盗号风险，模拟账号也一样
3. **别指望策略里联网拉数据**——新规焊死了，用内置行情
4. **别在策略里写 open() 存日志**——同样被禁，用 print 打到输出窗口
5. **别相信"策略稳赚"的任何话**——包括自己回测出来的结果（回测过拟合是新手最大的坑）
